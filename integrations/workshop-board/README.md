# 1202 研習問題留言板

架構僅為 Google 表單 iframe 收集＋Google Sheets 發布到網路的唯讀 iframe 顯示，沒有 API、留言卡片、Apps Script、排序、輪詢或前端收件計時。Google 收件與公開資料管理由擁有者操作。

## 網址設定

集中於 `src/workshop/questionBoardConfig.js` 的 `formUrl`、`sheetPublishedUrl`。後者只接受使用者從「檔案 → 共用 → 發布到網路 → 嵌入」提供的 `pubhtml` URL；拒絕 `/edit`，不把分享網址改寫成已發布網址。2026/11/17 使用者已提供正式網址，工作表 gid=26982722（表單回覆 1）。舊 `VITE_WORKSHOP_BOARD_URL` 不再使用。

嵌入網址使用官方支援參數 `widget=false`、`headers=false`、`chrome=false` 隱藏標籤、列欄標題及裝飾，保留指定 gid 與 single=true。這些參數只影響顯示，不是資料存取權限。

## 公開範圍與驗收

僅發布需展示工作表；先確認 A/B 與所有公開欄位／留言沒有姓名、電子郵件、學生資料或其他個人資訊。不得因為畫面只有兩欄，就宣稱其他發布資料無法存取；Google 端必須只發布選定工作表，不改原試算表分享或編輯權限。

直接發布原始回覆表不能保證安全逐則隱藏；隱藏資料列或在畫面過濾不是撤回公開資料的可靠方式。如需逐則管理，請由擁有者另設公開展示工作表，只放可公開資料，不在網站開發審核系統。已公開或快取資料也不能保證撤回。

送出問題後可重新載入網頁查看回覆；允許 Google 發布同步延遲。回覆區與 iframe 水平置中，網站不另外提供重整按鈕。不要使用假留言測試真實資料功能。iframe 的載入事件不證明資料、匿名存取或提交成功，需用未登入瀏覽器檢查公開表格、不能編輯及真實回覆。沒有網站端提交／關閉機制，表單自身控制收件。

官方嵌入說明：https://support.google.com/docs/answer/183965?hl=en 。
